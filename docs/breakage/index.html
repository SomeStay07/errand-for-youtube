When YouTube breaks Errand

YouTube changes its pages often. When that breaks a filter, it is logged here with three dates: when we found it, when the fix was written, and when Chrome Web Store started shipping it. Store review can take days, so the last two differ.

Seeing a problem that isn't listed? Report it.
