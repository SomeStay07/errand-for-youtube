What changed in Errand

Changes you'll notice, version by version. When a YouTube update breaks a filter, the fix is logged in Known issues.

0.3

  • With Hide recommendations on (the default), search results no longer show recommendation shelves like "People also watched". Untick it to get them back.
    • The "Latest from" shelf of a channel is hidden too; the channel card and its videos in the results stay.
  • With YouTube in a language that doesn't say "Shorts" (like Japanese), the Shorts tab and search chip are hidden too, after a brief flash.
  • The "!" now waits for a second failed check, so a slow page raises it less often. A real problem shows in about 12 s.
  • In YouTube's new video page layout, Show comments now moves keyboard focus to the comments.
  • The "Here for" label at the bottom of the page is now a link back to the search results for your errand.
  • The hint under the home question and on the welcome page no longer sends every browser to the puzzle icon: browsers Errand can't recognise get a general hint.
  • After an update like this one, the menu shows "What changed" for up to 3 opens. After 5 finished errands it asks for a store rating, at most 3 times; × ends it.
  • Smaller fixes: YouTube's button for hiding end cards no longer floats alone over the last seconds of a video.

0.2.1

  • Strict mode schedules that cross midnight (say 22:00-06:00) now count the night as the day it starts on.
  • The toolbar tooltip updates when a schedule window or a pause ends.
  • Picking "On a schedule" no longer locks the hours before you set them.
  • The end-of-video prompt closes with Escape and returns focus to the player.
  • Screen readers announce the 10-second countdown once instead of every second.
  • Smaller fixes: settings changes can't be lost while strict mode ends, a cleared time field keeps the saved time, Mixes stay visible on your playlists and library pages.
