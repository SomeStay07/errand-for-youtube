Unhook, UnTrap, Remove YouTube Suggestions and others compared

Most of these hide Shorts and recommendations. They differ in price, whether you can read the code, which browsers they run in, and the one thing each does best. If another one fits you better, use it.

When to pick something else

  • You want to block particular channels or words: BlockTube.
  • You watch in Safari on an iPhone or iPad: UnTrap or Control Panel for YouTube. Neither changes the YouTube app itself.
  • You want every possible switch: Control Panel for YouTube, UnTrap or Remove YouTube Suggestions.

Coming from Unhook

Most of Unhook's main switches have a match in Errand: the home feed, recommendations, Shorts, comments, the end screen and end cards, Mixes, live chat, the bell and autoplay. Errand starts from three presets instead of a list of switches, and the menu lets you change single parts later. Unhook can also hide things Errand doesn't touch, such as the video description or the top header. Settings don't carry over, so turn Unhook off while you try Errand.

Why Errand exists

Across about 4,000 reviews of extensions like these, the most common reason for a one-star rating was "stopped working after a YouTube update". Errand checks home, search, subscriptions, channel and video pages for Shorts that slipped through. On home, search and video pages it also checks that it still finds what it hides. If either check fails, its icon shows "!". Each breakage I learn about goes into the breakage log with the dates it was found, fixed and live in the Chrome Web Store. Errand doesn't block requests or touch ads, so it's unlikely to set off YouTube's ad-blocker warning.

Questions

Is Errand free?

Yes, and its code is open under GPL-3.0.

When was Unhook last updated?

As of November 3, 2026: March 22, 2026 in the Chrome Web Store and April 9, 2026 on Firefox Add-ons.

Which of these are open source?

Errand (GPL-3.0), Remove YouTube Suggestions (MPL-2.0) and BlockTube (GPL-3.0). Unhook and UnTrap are closed source. Control Panel for YouTube publishes its code on GitHub.

Does Errand block ads?

No. Use uBlock Origin for ads (in Chrome, uBlock Origin Lite); the two work together.

Free and open source, no account needed. Errand makes no network requests.
