Unhook, BlockTube and other YouTube blockers: an honest comparison

Most extensions in this list hide Shorts and recommendations. They differ in price, whether you can read their code, and the one thing each does best. If another one fits you better, use it.

When to pick something else

  • You want to block particular channels or words: BlockTube.
  • You watch on an iPhone: UnTrap; desktop extensions don't run in phone apps.
  • You want every possible switch: Control Panel for YouTube or Remove YouTube Suggestions.

Why Errand exists

Across about 4,000 reviews of extensions like these, the most common reason for a one-star rating was "stopped working after a YouTube update". Errand checks on every home, search and video page that it still finds what it hides, and shows "!" when something slipped back. It doesn't block requests or touch ads, so it's unlikely to set off YouTube's ad-blocker warning.
